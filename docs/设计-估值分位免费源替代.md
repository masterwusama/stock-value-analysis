# A 股估值分位免费源替代（fetch_valuation_em）· 结构设计 v1

> 状态：已实施（2026-10-04）。实施口径以本文为准；实施期一处源变更见 §1 末。
> 一句话：Wind 积分耗尽后 `valuation` job 是仅剩受影响面——A 股主体改走东财 datacenter
> （akshare `stock_value_em`，全历史日线序列本地落盘、分位本地算），HK 维持
> Wind 可选路径；产物契约与回灌路径几乎零改动。

---

## 1. 背景与问题

`valuation` job 现状（fetch_valuation.py 实测口径）：Wind skill CLI 批量问答句，每批 100 家、
每批两次调用（PE+PB / PS 分开），过筛池 5,340 家（A/HK 里管理分<30 或造假分>50 的不刷、
美股从不刷），单轮 108 次 ≈1,500 积分，13.9 积分/次，`--calls-cap 56` 挤成 1.9 天一轮。
积分 2026-09-20 耗尽后该 job 停摆（etl_job_log 最后 success 是 10-01，跑的是 09-30 的
trade_date），`valuation_pctile` 停止更新——列表页 PB 分位区间筛选的数据面在失血。

edb 已于 10-02 换免费源解决，valuation 是同一张清单上的最后一项。

**为什么免费源可行**：`ak.stock_value_em(symbol)` 单请求返回该股**全历史**日线
`数据日期/收盘/总市值/总股本/PE(TTM)/市净率/市销率…`。Wind 路径买的是「分位数」成品；
免费路径买的是「序列」原料——分位自己算，顺带把序列留在本地（详情页日后画 PE/PB
通道带就有了底子）。代价是每只一次请求（无批量接口）。

> **实施期源变更**：设计评审时按乐咕（`stock_a_indicator_lg`）写的；实施探针发现该接口
> 在仓库锁定的 akshare 1.18.64 里已移除，改用 `stock_value_em`（东财 datacenter，
> 与情绪/EDB 任务每天在打的同一家，礼貌策略一致）。实测差异：历史从 **2018-01** 起
> （非乐咕的 2005 起——10 年窗要随时间自然长满，`days` 自明）；**北交所有覆盖**
> （920002 实测 570 行）；亏损期 PE 用负数表示（正值窗口守卫直接适用）；单只 ~0.8s，
> 一轮 ≈110 分钟（比乐咕估算的 40~60 分钟长，超时上限放到 3h）。

## 2. 总体思路：动什么、不动什么

**不动**：

- `valuation_pctile` 表结构与「每股一行最新观测」语义（零 DDL）；
- `latest.json` → `import_valuation()` 回灌路径（产物同构；回灌侧唯一改动：`source` 列
  的组装现只透传 `windCode/date/round` 三键，**加一行 `src` 透传**，其余不动）；
- Wind 路径本体（充值后 `--source wind` 可整体切回，两条路径共存而非替换）；
- `_valuation_check.py` 既有 Wind 侧固定样本。

**新增**：

1. `collector/scripts/fetch_valuation_em.py`：序列采集 + 本地分位 + 写 latest.json；
2. `run.py` 的 `valuation` job 默认源切 `lg`，`--source wind` 保留；
3. `_valuation_check.py` 增补 lg 侧守卫样本。

## 3. 详细设计

### 3.1 序列采集（对齐 data/prices 的既有范式）

```
data/valuation/em/<code>.json = {code, updated_at, start,
                                 dates: [...], pe_ttm: [...], pb: [...], ps: [...]}
```

- **一次性回补**：5,553 只全量（不再过筛——积分约束消失，Wind 时代「管理分<30/造假分>50
  不刷」的覆盖洞顺带补平），0.35s 间隔 + 3 次重试 ≈ 40~60 分钟，断点续传按文件存在性；
- **窗口裁剪**：每只只留「今天 − 10 年 − 45 天」起的样本（分位窗口够用 + 停更判定余量），
  单只 ~55KB、全量 ~300MB，目录 gitignore，换机器重拉（与 data/prices 同一条款）；
- **日更**：东财单请求即全历史，重取尾部；0.4s 间隔 + 0.8s 请求 ≈ 110 分钟/天，调度从 05:05 提到
  **03:35**（避开 09:05 的 agro 与 05:05 遗留习惯，跑完照旧由 run.py 末尾统一回灌）。
  礼貌性条款：宿主是 datacenter-web.eastmoney.com（仓库情绪/EDB 每天在打同一家），
  间隔 0.4s 与既有习惯一致；首轮与首周日更盯响应质量，若被限流（429/截断）先放大
  间隔再议；
- **覆盖面**：北交所/部分新股乐咕可能缺——实测北交所有覆盖（920002 570 行）；仍保留空档占位逻辑兜底
  （fetch_daily_prices 对新浪缺口的同款处理），缺的置空不猜。

### 3.2 分位计算（本地化，口径显式化）

```
value  = 序列最新一档的 pe_ttm / pb / ps
window = 近 10 年内该指标的**正值**样本（≤0 剔除——对齐「亏损股分位无意义」守卫）
pct    = mean(window ≤ value) × 100        # 经验分位，与 Wind「近10年分位数」同义
days   = len(window)                        # 落 pe_days/pb_days/ps_days，前端「样本 N 个交易日」照常
```

守卫全套继承 Wind 路径语义：比率 ≤0 → 置空；序列最新日期距今 >45 天（停更/长期停牌）
→ 置空；pct 收敛到 0~100；新股短样本照落、靠 days 自明。

**口径差异要在说明书里写死的一条**：Wind 的「最新市盈率」问句未标注 TTM 与否，本路径
统一用 `pe_ttm`（与 `quote_daily.pe_ttm`、列表页显示一致）；切换日前后若个别股票分位
跳档，先查口径差再查数据。

### 3.3 产物契约与调度接线

- 写**同款** `data/valuation/latest.json`：`items: {"A:600519": {trade_date, fetched_at,
  round, src: "lg", pe: {pct, days, date}, pb: {...}, ps: {...}}}`（Wind 字段 `wind_code`
  在 lg 路径下为 null）——`import_valuation()` 按 `(code, market)` upsert；`source` JSON 列
  要能区分来源，依赖 §2 所述的**一行 `src` 透传**（不加则 src 会被组装时丢弃，落库行
  与 Wind 行无法区分——这是本设计唯一触碰回灌代码的点）；
- `run.py`：`JOBS['valuation']` 默认 `--source lg`；`--source wind` 时原批游标/积分上限
  逻辑原样生效（`--calls-cap` 仅 wind 源有意义）；`etl_job_log.stats` 记 `source` 与
  刷新家数；
- HK：东财该接口不覆盖港股。v1 维持现状语义——HK 行留在库中停更（与 09-20 后行为一致，前端样本
  天数列已能自明陈旧）；若 Wind 充值，`--source wind` 跑一轮可单独回补 HK。
  v2 可选：百度港股估值源（`ak.stock_hk_valuation_baidu`，仅 pe/pb、无 ps）再议。

### 3.4 守卫（_valuation_check.py 增补，零网络零库）

em 侧固定样本用「合成序列」测（不必真抓）：

1. 亏损段：pe_ttm 序列尾部为负 → pe 置空、pb 照算；
2. 停更：最新日期 = 今天−50 天 → 三项全置空；
3. 短样本：上市 200 天 → pct 照算、days=正值样本数；
4. 窗口边界：恰好 10 年前一天的样本**不进**窗口、十年内首日照进；
5. 自洽回算：抽 3 只真实文件，用独立实现重算分位比对落库值（防「算分位的代码」与
   「守卫的代码」同源抄错）。

## 4. 实施步骤

1. `fetch_valuation_em.py` 采集 + 分位 + latest.json（一天）；
2. `run.py` 接线与默认源切换、log 字段（半天）；
3. `_valuation_check.py` 增补 + 冒烟 `--probe 20`（对齐 Wind 路径的首轮验收习惯）（半天）；
4. 一次性全量回补（后台 40~60 分钟）→ 回灌 → `verify_import` 的估值分位覆盖断言重跑；
5. 使用说明书：采集表加一行 lg 源、口径差异条款、HK 停更语义（半天）。

## 5. 边界与不做的事

- 不做港美股免费源（美股本来就不在估值分位数据面内；HK 见 §3.3 的 v2 选项）；
- 不改 `valuation_pctile` 为历史序列表（那是另一个数据面；序列已留在 lg/ 工作目录，
  要落库等详情页画带时再立项）；
- 不做双源交叉校验常态化（守卫里一次自洽回算够了；两源口径本就有差，常态化比对只会
  天天报警）。
