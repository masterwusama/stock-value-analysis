# 江苏国泰(002091):停火拆掉汇兑的主炸弹——三柱之外第四根隐性柱亮起(事件快评)

> **基准日 2026-11-05(行情锚点 11-04 收盘 7.82 元,市值 127.3 亿,PE(TTM) 11.31,PB 0.80 破净。10-30→11-04 股价 +4.1%——转债临界价攻防+三季报后修复)。**
> **本快评为原裁决版研报(002091-江苏国泰-202610-2.md,10-29,「增持-弱 6.5~10,置信度下调」)的事件更新。**

## 事件与传导链

**11-04 双事件→国泰的四步传导**:

```
停火草案 → 油价 -15%
  → ① 美国通胀压力减轻 → 美联储降息空间恢复 → 美元反弹/人民币升值放缓
    → ② 汇兑损失方向反转(2026 前三季 ~-4.5 亿,2027 归零/转正预期)
  → ③ 关税生态改变(民主党国会) → 贸易伙伴抵制空间变大 → 对华关税降温
    → ④ 纺织出口环境边际改善(国泰出口占 83%)
```

**原研报中对应段落的精确兑现**:

| 原裁决版论述 | 事件影响 | 方向 |
|---|---|---|
| §3.2「汇兑损失约 4.5-5 亿为非现金+可逆项;若 2027 人民币企稳,财务费用基数反转」 | **反转触发**:停火→人民币升值压力放缓→汇兑转回的时点提前 | ↑ |

| §6.1「Q4 扣非回正+人民币企稳=升 N2 条件」 | **两个条件同时亮起** | ↑ |

## 汇兑反转的量化弹性

| 情景 | 2027 汇兑损益 | 2027E 归母 | 弹性 |
|---|---|---|---|
| 悲观(人民币续升至 6.50) | -3 亿(持续) | 9.5-10 亿 | 基准 |
| **中性(停火+人民币 6.90-7.10 区间)** | **0 亿(归零)** | **13-14 亿** | **+3-4 亿** |
| 乐观(人民币贬至 7.20+) | +1-2 亿(转正) | 15-16 亿 | +5-6 亿 |

**推演注**:仅汇兑归零一项,2027E 归母就从原研报的 10.2-10.7 亿修至 13-14 亿(+28~33%)——这不是经营改善而是会计反转,但市场按表观增速定价,归母 +30% 的修复足以推动估值中枢上移。

## 档位裁决:增持-弱(B1) → 增持-中(B2)

**升档依据**:

1. **第四根柱亮起**:原裁决版的三柱(股息/破净/转债)+新增汇兑反转期权——四柱结构的期望回报从 +7.5% 上修至 +12-15%(汇兑归零的 30% 概率 × +3-4 亿弹性);
2. **升档触发器双重击穿**:原研报 §6.9 的升档条件「Q4 扣非回正+人民币企稳」——停火事件使人民币方向从「续升」切换到「企稳/走弱」的通道;
3. **转债临界价的正反馈**:现价 >临界价+促转股的日历确定性(2027-07 到期前的 8 个月)——**时间之友的结构**。

**未升更高的原因(增持-中而非强)**:

1. 汇兑反转是**推断而非事实**——停火尚是草案,人民币方向取决于美联储的实际路径;11 月中间价是确认线;
2. 瑞泰(电解液)的扣非竞争力走弱(原研报 §6.2)——主业的经营改善仍待年报验证;
3. 破净 0.80 的收敛依赖市场风格(价值/红利)——2026Q4 的成长风格若延续,折价持续。

**区间 6.5~10 框架不变,中枢从 7.9 上修至 8.5-8.8**(汇兑反转概率 30-40%×弹性 +1 元)。
