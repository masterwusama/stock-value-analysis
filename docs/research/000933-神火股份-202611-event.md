# 神火股份(000933):停火的五维传导——煤炭分部的能源替代效应是最大变量(事件快评)

> **基准日 2026-11-05(行情锚点 11-04 收盘 26.06 元,市值 586 亿,PE(TTM) 7.32,PB 1.93。10-30→11-04 股价基本持平——市场未定价煤炭回调风险)。**

## 五维传导分析

### ①喷吹煤价格回调:★★★ 最大变量(本篇核心分析)

神火是三只铝股中**唯一持有大规模煤炭业务**的(2026 计划商品煤 695 万吨,永城无烟喷吹煤为主)。原研报的核心逻辑之一是「煤铝双击」——喷吹煤年内从 1,010 元涨至 1,710 元(+70%)为煤炭分部贡献了 H1 约 7.4 亿利润。

**停火的传导链**:

```
停火 → 油价 -15% → 全球能源板块情绪回落 → 煤炭作为替代能源的价格预期承压
  → 国内动力煤/焦煤/喷吹煤面临情绪面回调压力(短期 5-10%)
  → 神火煤炭分部利润边际下降
```

**量化**:喷吹煤每跌 100 元/吨:
- 年销售 695 万吨 × 100 元 = **-6.95 亿收入** → 扣税+少数股东后约 **-4-5 亿归母**
- **若喷吹煤从 1,710 回调至 1,600(-6%)→ 煤炭分部年利润 -4-5 亿**
- **若回调至 1,500(-12%)→ 煤炭分部年利润 -9-10 亿**

**缓冲因素**:
- 喷吹煤价格由钢铁需求端驱动(高炉辅料),而非直接锚定油价——**钢铁需求不因停火改变**；
- 国内煤炭定价机制以长协为主(约 70%),现货跳价影响短期不改全年中枢；
- 喷吹煤从 1,710 回落到 1,400-1,500 仍是年内高位(年初 1,010)。

**焦煤期货 JM 主力 1,365(11-03)已从年内高位回落约 10-15%**——黑色系在停火前已开始回调,但这是钢铁需求疲软驱动而非油价。**喷吹煤作为无烟煤分支,走势更独立于焦煤**,若焦煤企稳则喷吹煤的回调幅度有限。

**结论:煤炭分部的停火风险是「情绪面回调 5-10%」而非「趋势性下行」——但弹性大(每 100 元/吨=4-5 亿归母),需要列入验证点。**

### ②铝分部:与云铝共享供给红线的支撑

LME 铝 3,040 美元(11-03)在停火消息后基本持平——**铝价不因停火直接下跌**(供给红线 4,500 万吨是结构性支撑,与中东无关)。氧化铝 2,621 也持平(几内亚铝土矿供给驱动)。

**神火铝分部(新疆 80 万吨自备煤电+云南 90 万吨水电)不受停火影响**——新疆的自备煤电成本内部化,云南的水电成本与油价无关。

### ③新疆自备煤电的「内化双刃剑」

神火新疆基地 80 万吨电解铝使用自备煤电(4×350MW)——**煤价下跌对神火的双向效果**:
- **外售煤炭分部**:收入下降(负面)
- **自用发电成本**:煤价降→发电成本降→电解铝成本改善(正面)
- **净效果**:煤炭外售量(~695 万吨)>> 自用发电煤耗(~300 万吨级),**外售损失大于自用节省——净负面**

### ④汇兑:小幅正

云南神火有部分海外销售的美元敞口——人民币升值压力放缓→汇兑收敛。弹性约 +0.2-0.4 亿/季(比云铝小,比明泰略大——云南基地美元敞口)。

### ⑤运输:重货双板块的物流改善

煤炭+铝锭都是重货(铁路/公路/海运),油价 -15% → 物流成本边际改善。弹性约 +0.2-0.3 亿/季。

## 档位裁决

**观察(区间 19~33)维持,但从「上沿」微降至「中性」——煤价回调是新增风险项**。

原研报的期望回报约 8-10%(观察上沿)——停火事件后:
- 煤炭分部的新增不确定性使期望微降至 **5-8%**(观察中性)；
- **喷吹煤 1,600 元/吨为警戒线**——跌破则 2026E 归母从 91-97 亿下修至 85-90 亿,中枢从 26.5 下移至 24-25;
- **若喷吹煤企稳 1,650+**:煤炭分部利润不受影响,停火对神火仅剩汇兑+运输的小幅正贡献。

**三维更新**:观察-中性(从观察上沿微降)/中性-4/中性-4——原研报的三维维持,仅推荐度微调。
