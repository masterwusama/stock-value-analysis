# 设计-世界局势推演(2026-11-15)

## 1. 背景与定位

商品与资产的定价里,「世界局势」是唯一还没被系统化的因子:

1. 黄金因子记分卡两连 FAIL 判死(IC +0.014/-0.005,见 docs/研究-大宗商品记分卡回测判死-2026-10.md),留档的重试方向是**事件驱动/断点模型**——本模块是该方向的落地形态:不预测价格,结构化事件与传导,把应验与否变成可追踪的台账。
2. 对局势的分析此前完全是临时性、一次性的,没有持续积累、可复盘、可对照的框架。

定位:**局势研究看板**——温度计(现状量化)× 活跃事件(局势内容)× 情景树(前瞻推演)× 敏感度矩阵(事前先验)× 历史剧本(类比推理)× 应验度(事后闭环)。覆盖面发散到商品之外:板块(航运/化工/民航/半导体)、汇率、宏观资产。

### 纪律红线(继承全站既有纪律)

| 纪律 | 来源 | 本模块的落地 |
|---|---|---|
| 不做复合评分记分卡 | 黄金两连 FAIL 判死;commodity.py:452 注释 | 温度计=多个单一事实并排(各自分位),不做加权综合分;形态对照是人工指纹文案不算法判别 |
| 概率显性标注主观 | 评价体系v2 的置信度纪律 | 情景树概率带「主观估计·非模型输出」标签,页面头注与卡片双处标注 |
| 事实核对不评分 | 老版预警应验度计分法 | 应验度=窗口内实际涨跌 vs 预期方向的三档事实记录(confirmed/flat/refuted),不打分 |
| 弱源显性标注 | 歌尔研报纪律 | 美元宽口径(FRED 滞后)等陈旧序列卡上标「陈旧N天」;GEO_OIL_CU 起点短的序列标 begin |
| sector 面不自动核对 | aviation-stress 的业务结构差异教训 | 代理序列映射只覆盖商品/fx 面;sector/stock 面标「人工核对」 |

## 2. 六板块设计

### ① 局势温度计(10 卡)

| code | 指标 | 来源 | 语义 |
|---|---|---|---|
| GPR | 地缘政治风险指数(月) | gold 模块复用(Caldara-Iacoviello) | 局势直接读数,1985→ |
| VIXCLS | VIX 恐慌 | gold 模块复用(FRED) | 即时恐慌 |
| GEO_GOLD_OIL | 金油比=伦敦金÷WTI | **本模块派生** | 避险×能源双温度 |
| GOLD_SILVER | 金银比 | gold 模块复用 | 恐慌溢价集中度 |
| CU_GOLD | 铜金比 | copper 模块复用 | 风险偏好/衰退指纹 |
| GEO_OIL_CU | 油铜比=WTI÷LME铜×1000 | **本模块派生** | 通胀交易 vs 增长交易 |
| BRENT_WTI | 布伦特-WTI 价差 | crudeoil 模块复用 | 海运 vs 陆上紧张度 |
| DTWEXBGS | 美元宽口径 | gold 模块复用 | 全球定价分母 |
| DFII10 | 10Y 实际利率 | gold 模块复用 | 金融条件核心 |
| USDCNY_FIX | 人民币中间价 | gold 模块复用 | 贬值压力=摩擦对冲形态 |

每卡:当前值+52周分位+全史分位+1月变化+一句解读。**8 个复用序列零新增采集**——同 code 二次注册会被 `_import_cmd_series` 的 upsert 翻转 commodity 字段(互灌),故温度计复用序列绝不进 worldgeo.json,API 直接按 code 跨 commodity 读库。

派生序列(世界局势模块唯一采集面,零网络):
- `GEO_GOLD_OIL = gold.XAU_USD ÷ crudeoil.CL_MAIN`(盎司/桶)——飙升=避险与供给冲击共振(海湾战争/2020-04/俄乌),温和走低=需求主导行情。
- `GEO_OIL_CU = crudeoil.CL_MAIN ÷ copper.CAD_MAIN ×1000`——通胀交易 vs 增长交易;方向语义看分母谁先动(铜先崩=需求衰退,油先崩=供给过剩)。
- 采集器 `fetch_worldgeo.py` 读兄弟模块 data/*.json 按日内连接相除;兄弟缺席时从上轮产物继承(warnings 注记);调度 **07:55 殿后**(晚于 gold 06:05/copper 06:25/crudeoil 06:55 保证当日原料落盘)。
- GEO_OIL_CU 起点 2016-11(新浪外盘 CAD 源长度),全史分位覆盖不了完整周期——卡上展示 begin。

### ② 形态对照手册(静态)

六个典型组合→局面判别的人工指纹:地缘避险局/流动性恐慌局/衰退定价局/海运紧张局/通胀交易局/局势平静期。组合判别留给人,手册只给指纹。

### ③ 活跃事件(events.json 人工档)

事件对象:`{id, date, title, category, region, status, summary, assets[], expectation{window_days,notes}, evidence[], related_reports?[], playbook_ref?}`。

- `assets[]`:资产面四型(commodity/fx/sector/stock),每条 `{type, ref, direction, strength 1-3, channel, horizon}`。
- **direction 是对该资产价格的方向不是修辞**——航空在停火中是 bullish(成本降)。
- category 枚举与矩阵列一致:地缘冲突/停火缓和/制裁出口管制/关税贸易/央行储备/OPEC供给/航运通道/科技博弈/选举政策/全球流动性。
- horizon=structural 的事件(央行购金)是 regime 不是事件,单列不进应验度核对。
- evidence 用文字描述来源(不存易失效 URL)。
- 首轮录入 4 个:中东停火周期(2026-11-05)、美国对华出口管制博弈、央行购金长趋势(2022 起)、美国国会格局变化。

### ④ 情景树(scenarios.json 人工档)

`{set_id, linked_event, scenarios[]}`,每情景 `{name, probability, prob_note, narrative, assets[{ref,direction,magnitude,channel}]}`。概率之和必须=1(verify 脚本校验);magnitude 用「中枢±」语言不写点位。当前主导局势(停火周期)三情景:稳固 0.50/拉锯 0.35/升级 0.15。

### ⑤ 敏感度矩阵(geo_matrix.json 人工档)

13 资产(8 商品+人民币+4 板块)×10 事件类别,每格 `{d:±1/0, s:0-3, note}`。d×s ∈[-3,3] 进 echarts heatmap(红=利多/绿=利空,A股语义)。**这是事前先验不是回测产物**——历史经验弹性的自动回测是 P2。两个特殊列定义:「全球流动性」=收紧/恐慌类事件;「选举政策」=执行力度变量(传导均边际)。

### ⑥ 历史剧本库(playbooks.json 人工档)

5 个剧本:2020-04 负油价 / 2022-02 俄乌 / 2023-03 硅谷银行 / 2024-2026 霍尔木兹停火周期(亲历) / 2025-05 BIS 乙烷断供。每剧本 `{trigger, chains[传导链], assets[峰值反应], duration, fade_note, lesson}`。lesson 是方法论提炼(敏感度事前可算/制裁定价两层/温度计指纹判别事件类型等)。

### 应验度追踪(API 读时合成)

事件日→date+window_days 窗口内,资产代理序列首末涨跌 vs 预期方向:

- 代理映射 `_VERIFY_CODE`(world_geo.py):crudeoil→CL_MAIN、gold→XAU_USD、silver→XAG_USD、copper→CAD_MAIN、aluminum→AHD_MAIN、lithium→LC0_CLOSE、ferrous→RB0_CLOSE、agri→LH0_CLOSE、fx_cny→USDCNY_FIX、natgas→NG_MAIN、jetfuel→AV_JETFUEL。
- verdict:|chg|<1%=flat,方向一致=confirmed,反向=refuted(阈值 events.json `verify_threshold_pct`)。
- 未到期=pending;无映射(sector/stock)=manual;窗口数据<2 点=insufficient。
- 汇总 `verify_summary{done,confirmed,refuted,flat,due}` 挂事件级。

## 4. 分期

- **P0(本期)**:温度计 10 卡+形态对照+事件库+情景树+矩阵热力图+剧本库+商品/fx 面应验度。
- P1:传导链图谱可视化(事件→中间变量→商品→板块,echarts graph,链数据人工积累)、股票面 verify 自动化、掘金台活跃事件提示 pill。
- P2:GDELT 候选事件流(噪音过滤挑战大)、世界局势周报自动生成、矩阵经验弹性的历史回测(用价格序列对历史事件日期回测各格子)。
