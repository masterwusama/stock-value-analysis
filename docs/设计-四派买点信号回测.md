# 四派买点信号回测（buy_validity）· 结构设计 v1

> 状态：已实施（2026-10-04），判决书见文末 §7 与《使用说明书》效度小节。
> 一句话：给「格攻 / 格防 / 施洛斯 / 巴菲特」四条买点线做收益侧出厂检验——
> 「股价从线上方跌进买点」这一事件发生后的 6 个月 / 1 年 / 2 年，超额收益是多少、
> 相对「同样便宜但没进线」的邻域股还有没有增量信息。

---

## 1. 背景与问题

四派买点是本站最核心的输出：`score_daily` 每日物化 `buy_graham_agg / buy_graham_def /
buy_schloss / buy_buffett` 四列（连同三档卖价），列表页筛选走这张物化表，auto_screen 则
当场调 `scoring.py` 现算——两处是同一份公式的两个消费端。
但出厂检验只做过一半——`backend/scripts/` 下的效度家族（r / rr / g / v / bm / ta / trap /
dip / fraud / st_validity）覆盖了 R、V、G、陷阱、造假、ST 各分项，**唯独买点线本身从未做过
收益侧检验**。rr_validity 的判决书已经写死「R 是排雷与选质的入口，不是买点」，那么真正
自称「买点」的四条线就更没有理由豁免同一道检验。

数据面其实早已备好，只是没人用完：

- `collector/data/prices/<code>.json`：全 A 5,553 只、2019-01 至今的**后复权日线**
  （fetch_daily_prices.py 一次性回补，新浪源、断点续传），其文档开头就写明
  「为 scripts/rr_validity.py（R 的收益侧回测）供数」——但 rr_validity 只用了它的
  **收益率**，从未用它的**价位**；
- 效度家族已沉淀的点时（point-in-time）加载器：`fraud_validity.Avail`（年报可用日）、
  `trap_validity.TABLES`（三张财报表 as-of 切片）、`g_validity.quintiles_of`（分档）——
  历史「某天某公司的财务状态」可以无前视地重建；
- `scoring.py` 的 `price_references()` 是买点公式的**单一事实源**（Python/JS 双实现有
  parity 校验守着）。

缺口只在两处：① `score_daily` 的历史快照只从 2026-09-03 开始积累（约一个月），历史买点
信号不存在，必须点时重构；② `data/prices` 只存 hfq 收盘，而买点比较是「名义价 ≤ 名义买价」，
复权价与名义价不可直接比。

## 2. 总体思路：动什么、不动什么

**不动**（全是有纪律守着的既有资产）：

- `scoring.py` 买点/卖价公式一字不改——历史买点价**直接调用** `price_references()` 复算，
  不另写第二份公式。任何公式改动天然使旧回测作废，回测结果须记当时的 git 短哈希；
- 效度家族脚本与 `_tmp/r_obs.json` 面板缓存；
- 数据库零 DDL、零回灌、零调度——本设计与 rr_validity 同类，是**离线研究**，不是在线功能；
- `data/prices` 现有字段语义（`closes` 仍为 hfq，收益口径不变）。

**新增**：

1. `fetch_daily_prices.py` 产物**加一列**原始（不复权）收盘 `raws`（向后兼容：旧文件缺
   `raws` 字段视作待补，重拉该只一次；`--refresh` 续拉时顺带补齐）；
2. `backend/scripts/buy_validity.py`：四派买点事件研究（本文主体）；
3. 《使用说明书》新增小节，像 R 那条一样**写死读法**（无论结果好坏都落档）。

## 3. 详细设计

### 3.1 历史买点信号的重构（无前视）

**信号网格**：A 股，2020-01 ~ 2025-12 每月**最后一个交易日**（月末网格而非年报日——买点
是价格驱动的事件，年报日太稀）。约 72 个月 × 5,553 只 ≈ 40 万个「公司 × 月份」格点，
每格复算一次 `value_analysis` + `price_references()`（毫秒级），离线全量数十分钟内跑完。

**每格构造**（复用效度家族加载器；关键是别自己拼公式，把「公司 dict」重建出来交给引擎）：

调用链是 `d → value_analysis(d, now=信号日) → price_references(d, va)`——`price_references`
吃的不是财务行，是**完整 company dict + 价值分析输出**。重建 `d` 的原料全在库里：

| 输入 | 来源 | 前视防护 |
|---|---|---|
| 中文科目行（indicators/income/balance/cashflow 的原格式 dict） | `fin_*.extras`（**无损原件**，`fraud_validity.load_batch` 已有整批加载先例） | 只取「可用日 ≤ 网格日」的报告期；`load_announce` 的 `{报告期: 可用日}` 覆盖全部报告期（**含季报**），TTM 的 as-of 滚动可行 |
| 股本 | 引擎自带 `_share_count()`（scoring.py:737，从资产负债表行求，带 bps 兜底）——不另造口径 | 同左 |
| 每股净资产 / NCAV / EPS-TTM / 5 年净利 CAGR / fair_pe | `value_analysis` / `price_references` 自己算 | 同左 |
| 当日名义收盘（行情快照的价格项） | `data/prices` 的 `raws` | 序列本身是历史事实 |
| 分红行 / fin_note | `dividend` / `fin_note` 表，`now=信号日` 截断 | 同左 |

产出四派买点价后，事件判定：

```
事件（派 P，折扣 D）= 上月网格日 名义收盘 > buy_P × D%，本月网格日 ≤ buy_P × D%
D ∈ {100（踩线）, 80（再打八折，对齐 auto_screen --discount）}
```

**去重**：同股同派同折扣，180 天内只保留首个事件（事件研究的标准处理，避免一次深跌
产生一串伪独立观测）。上市不足 250 个交易日的格点剔除（新股效应与买点语义无关）。

### 3.2 收益与对照

- 收益 = `fwd_return()`（rr_validity 同款，现为整数年步进，**需扩半档**支持 6 个月腿）：
  事件日收盘（hfq）→ 6 个月 / 1 年 / 2 年纪念日后首个交易日收盘，点对点总收益；
  截尾申报：2 年腿只有信号日 ≤ 2024-09 的观测可判，其后自然缺失（判不动不进分母），
  样本表逐年 N 要把这个递减显出来；
- **市场对照（超额）** = 个股收益 − 同（信号月 × 期限）**全队列中位**——事件天然聚类在
  市场底部，不减同期中位就会把择时 beta 记成选股 alpha；
- **邻域对照（本设计的要害）** = 同信号月、同行业（证监会大类）、同 PB 三分位、
  **但未进任何买点线**的股票池中位。四派买点在构造上就是「便宜 + 资产/盈利锚」，事件组
  跑赢市场可能只说明「便宜有效」，不能归功于「这条线画得好」。邻域对照回答的是：
  **这条线相对于「同样便宜」有没有增量信息**。

### 3.3 预登记判决线（跑之前写死，家规）

- **甲（单派成立）**：某派事件组（D=100）超额中位 1y > 0 且 2y > 0，逐年方向 ≥2/3 同向。
- **乙（线的增量）**：事件组 2y 超额 − 邻域组 2y 超额 ≥ 0（容 −1.5pp，同 TOL_PP 量级）。
  甲过而乙不过 = 「便宜有效、线没添信息」，读法降级为「买点是便宜的另一种写法」。
- **丙（不判，只印）**：四派横评表（同一人群互比哪条线质量高）；D=80 对照（打折线是否
  显著更优）；前视污染对照——用**今天**的财务算历史买点（R_full 同款污染），只看形状。

### 3.4 偏差申报（写进判决书，不许省）

1. **幸存者偏差，方向对本设计更不利**：退市股在 `data/prices` 无文件、整条观测判不动；
   陷阱型便宜股（买点密集区）恰恰死得多，事件组收益被系统性**高估**——甲量到的是上界。
2. **风格窗口**：信号窗 2020-2024 的后两年正逢红利/微盘占优、质量成长杀跌（rr_validity
   同窗），对深度价值线**友好**；结论须标注窗口，不得外推为全周期性质。
3. **月末快照近似**：盘中/周内首次触线与月末网格日可能差数日，深度价值语境下影响有限，
   但属已知近似。

## 4. 产物与用法

```
cd backend; python -X utf8 -m scripts.buy_validity            # 全量：判决书 + 四派表
python -X utf8 -m scripts.buy_validity --dump ../_tmp/buy_obs.json   # 事件面板缓存（复跑免重构）
python -X utf8 -m scripts.buy_validity --school schloss --discount 80,100
python -X utf8 -m scripts.buy_validity --check-live           # 同构对拍（见下）
```

**同构对拍（必做守卫）**：研究网格（2020~2025）与 `score_daily` 的物化窗（2026-09-03 起）
天然不重叠，重建路径是否真与在线路径同构不能靠嘴说——`--check-live` 把网格多跑一个
2026-09-30 格点，逐派与 `score_daily` 当日物化的 `buy_*` 比对，误差超容差（财报期不同步
等可解释差异单独列名）即 FAIL。这是整个「点时重构」方法论的直接证据，不过线不进判决书。

只读库 + 本地价格文件，零积分、零网络（除补拉 raws 的一次性回补）。

## 5. 实施步骤

1. `fetch_daily_prices.py` 加 `raws` 列 + 一次性补拉（≈75 分钟，与首轮同量级）；
2. `buy_validity.py` 面板构造（复用 TABLES / Avail / quintiles_of / fwd_return）；
3. 事件判定 + 双对照 + 判决书；
4. 结论落《使用说明书》（§效度小节，格式对齐 R 那条）；
5. （hook，不在本期）**前向信号台账**：`score_daily` 已每日物化 buy_*，SQL 即可圈
   「今日在买点内」清单——那是「信号日报」条目的接口，本文只预留不实施。

## 6. 边界与不做的事

- 不覆盖港美股（prices 只备了 A；港美股买点锚的口径差异另议）；
- 不做事件日内精确入场时点、不建模交易成本与冲击（读法定格「证据合计」，同 rr）；
- 不进调度器、不建表、不改前端——回测是研究，不是产品；若日后判决书支持，
  「信号日报/行业买点密度」再以独立设计立项。

## 7. 实施结果（2026-10-04 首跑）

**实施期修订**（与 §3 设计的偏差，均为 check-live 对拍逼出来的）：

1. 可用日：指标行切片用**三表可用日并集**（任一报表记录该期公告日即可入）——只用
   利润表代切会错杀只在指标表有行的季报，301/688 段数百家的 TTM 窗口因此断掉；
2. 股本先验：**最新一期归母权益 × 同报告期每股净资产**。年报期配对会拿旧股本
   （2026 年送转/增发的新股份只在半年报 bps 里），NCAV 锚系统性高 ~30%（568 家、
   中位 +31% 实测）；把实收资本当先验则会被万元口径科目（688428 实测）放大 10⁴ 倍；
3. raws 回补实测 114 分钟（双请求/只），不是估的 75 分钟。

**同构对拍（--check-live，2026-09-30 全市场 5,542 家）**：施洛斯 0.5% / 格防御 0.7% /
格进取 2.7% / 巴菲特 3.3% 不一致，全部落在预登记 <5% 放行线内；残余两类——
score_daily 是抓取时点产物（其后深抓回补的财报行重建侧反而更全）与 ±10% 内小锚差。

**判决书（预登记线，2020-01~2025-12 网格、面板 317,083 条）**：

| 派 | 事件数(D=100) | 6m/1y/2y 超额中位 | 邻域差(2y) | 甲 | 乙 |
|---|---|---|---|---|---|
| 施洛斯 | 937 | +1.4% / +3.7% / **+4.7%** | **+2.0pp** | PASS | PASS |
| 施洛斯 D=80 | 459 | +0.0% / +0.2% / +4.2% | — | PASS | — |
| 格防御 | 1,086 | −0.7% / −2.3% / −2.4% | −3.7pp | FAIL | FAIL |
| 巴菲特 | 1,690 | −0.9% / −3.4% / −3.0% | −4.1pp | FAIL | FAIL |
| 格进取 | 28 | 不足 30 不判（NCAV 股近乎绝迹） | — | — | — |

**读法**：账面线（PB 锚）在本窗口拿到收益侧证据且对「同样便宜」有增量信息；盈利倍数
线（EPS 锚）与 R 同因失败（2021~2023 质量成长风格杀跌）；格进攻样本太稀，留待更长
窗口。幸存者偏差方向对深价值不利，施洛斯 +4.7% 是保守读法下的上界；风格窗对资产线
友好，外推需谨慎。
