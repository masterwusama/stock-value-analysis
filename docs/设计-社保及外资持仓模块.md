# 设计:社保及外资持仓(#/inst,2026-11-18 设计)

## 定位

社保基金与外资(QFII/北向)是 A 股「聪明钱」里披露最规整的两类:季报十大流通股东
强制披露,组合命名(全国社保基金一零X组合)可直接归因到委托管理人;外资侧 QFII
同表可得。本模块是**机构持仓跟踪工具**:看国家队与外资在买什么/卖什么/抱团在哪,
并与掘金台交叉验证(社保新进的票在推荐体系里是什么档位)。研究工具非投资建议;
季报口径天然滞后最多 3 个月,页面对每个数字带报告期 as-of,不冒充实时。

## 架构

采集面 → JSON 工件 → `--only-inst` 落库 → 读时合成,与 ETF/forecast 同一套纪律:

| 数据域 | 来源 | 缺失时 |
|---|---|---|
| 机构持仓明细 | `inst_holding` 表(采集:data/freeholders_{期}.json) | 底座,空态+横幅 |
| 现价/涨跌/市值/推荐分 | `quote_daily` + `score_daily` 最新日(库) | 行情列「—」 |
| 北向季末快照(P1) | `inst_north` 表 | 北向列「—」+口径横幅 |
| 港股外资(P1) | `inst_hk_holder` 表(源待 spike 定) | 港股 tab 空态「源探测中」 |
| 机构字典(P1) | `inst_registry`(人工结构化 JSON→表) | 实体归并列降级为原始名 |

降级链纪律:持仓表缺失只空态+标注,绝不缺列冒 0;每个数字带报告期。

## 口径纪律(八条,全部显性标注不填充)

1. **十大流通股东口径**:只覆盖进前十的组合/机构——社保持小票排不进前十是
   系统性漏采,页面固定「前十大口径」横幅,不试图补全。
2. **战略持股污染**:QFII 表含战略入股(汇丰/交行 25%、华侨银行/宁波银行 18.7%
   实测在列)。不硬删:占总股本≥5% 且连续≥4 期「不变」→ 打「战略持股」标签,
   默认视图可一键过滤。
3. **报告期漂移**:`IS_MAX_REPORTDATE` 含非标日期(实测鹏鼎控股 2026-10-19 定增
   名单混在 2026三季报 期)。存 `REPORT_DATE_NAME` 区分标准期/临时披露,总览与
   趋势只统计标准期(一季报/中报/三季报/年报),临时披露单独小节。
4. **社保≠国家队幻想**:社保组合由基金管理人受托管理(博时/易方达等),决策人
   是管理人不是理事会;tooltip 讲清,不做「国家队护盘」叙事。
5. **社保≠养老金**:HOLDER_NEWTYPE 全枚举 P0 探测,「基本养老保险基金」若独立
   类型则独立 tab 或并入标注,不默认混算。
6. **北向已死为日度**:2024-08-19 起港交所停个股日度,现仅季末快照——北向列
   一律标注「季末·2024-08 起停日度」,绝不把季末数当日度叙事。
7. **港股 SDI 是大股东口径**:≥5% 门槛、±0.5pp 变动触发,跌破 5% 即消失≠清仓;
   托管行(BNY/Citibank NA/JPMorgan Chase NA)是名义持有人非受益人——inst_registry
   标 custodian,不计入外资机构持仓主体。
8. **QFII 实体归并**:贝莱德/摩根等多实体多拼写,inst_registry aliases 归一
   「贝莱德系」;P0 先存原始名,P1 归并列。

## 数据模型(entities.py 新增)

```python
class InstHolding:   # 机构持仓明细(A股,十大流通股东口径)
    # PK (holder_code, secu_code, end_date, shares_type)——同股同期多 shares_type 防撞
    holder_code: str      # 组合/机构代码(HOLDER_NEW),如 70010101
    holder_name: str      # 全国社保基金一零一组合 / 香港上海汇丰银行有限公司
    holder_type: str      # HOLDER_NEWTYPE 原值(社保/QFII/保险/…)
    holder_type_sub: str  # HOLDER_TYPE 细分(全国社保基金/基本养老保险基金/…)
    secu_code: str; secu_name: str; secu_market: str  # A股
    end_date: str         # 报告期 YYYY-MM-DD(原样,含临时披露日)
    report_name: str      # 「2026三季报」/临时日期原文
    is_std_period: bool   # 标准期 True / 临时披露 False
    hold_num: float; free_ratio: float; free_ratio_qoq: float
    change_type: str      # 新进/减持/不变/增减数原文
    change_num: float|None
    hold_mktcap: float    # 持仓市值(元,披露日价)
    holder_rank: int|None
    updated_at: datetime
    # idx: (secu_code,end_date) / (holder_type,end_date) / (holder_code,end_date)

class InstNorth(P1): # 北向季末快照
    # PK (secu_code, end_date);hold_num/free_ratio/updated_at

class InstHkHolder(P1): # 港股外资(SDI/EM F10,源定后字段微调)
    # PK (stock_code, holder_code, filing_date);holder_group(归一)/shares/pct/
    # prev_pct/delta_pp/note(custodian 口径标注)/updated_at

class InstRegistry(P1): # 机构字典(人工 JSON→表)
    # PK holder_group;aliases JSON/holder_type/sub/type_tag(主权基金|全球资管|
    # 战略股东|托管行)/note
```

## 采集与调度

- `collector/inst/scripts/fetch_inst.py`,job 名 `inst`,run.py 注册
  `--only-inst`;**周日 10:25**(worldgeo-weekly 10:15 后错峰):三类全量最新期,
  pageSize=500(社保 2 页+QFII 6 页+保险 2 页,sleep 0.4+RETRY 3,fetch helper
  用 forecast 同款),实测数据量单期 <5k 行、<3 分钟。
- 工件:`data/freeholders_{YYYYMMDD}.json` 按报告期一文件(历史期冻结不改,
  周任务只重写当期)+`data/manifest.json`(各类型行数/最新期/updated_at,
  供行数断言与页面横幅)。历史回填:`scripts/backfill_inst.py` 一次性拉近
  12 个报告期(约 5 万行),回填工件冻结入仓。
- 行数断言:社保<500 行 / QFII<1500 行即 job 告警写 etl_job_log(页面迁移
  防线——jgcc 404 前车之鉴)。
- P1 `inst-north`:月度 day=3 05:35,幂等 upsert;P1 `inst-hk`:源定后定频。
- 云端零采集面:采集只跑本地调度器,datacenter-web 本地已验证可达,无 push2
  类拉黑风险;云端走仓库 JSON→import,与 commodity 各组同路。

## API(backend/app/api/inst.py,prefix /api/inst,fingerprint 缓存 600s 同 forecast)

| 端点 | 内容 |
|---|---|
| `GET /api/inst/overview` | 最新标准期摘要:各类型持仓总市值/标的数/组合数、新进/增持/减持 TopN、抱团榜(≥N 组合同持)、临时披露小节、as-of |
| `GET /api/inst/holding?type=&period=&sort=&page=` | 明细表;join quote_daily/score_daily 取现价/推荐分;过滤器:变动类型/组合/最低市值/仅掘金台覆盖/剔除战略持股 |
| `GET /api/inst/stock/{code}` | 单股:各类型持仓历史序列+北向季末序列(P1),报告期齐全带 as-of |
| `GET /api/inst/org/{holder_code}` | 组合视图:该组合全持仓+环比调仓(跟随单一组合) |
| `GET /api/inst/consensus`(P2) | 共识信号:社保×QFII 同期同向、双重背书、抱团加深 |
| `GET /api/inst/hk/*`(P1) | 港股侧 summary/单股/机构视角,源定后定型 |

## 信号层(P2,标注制不拦截)

- **共识**:同报告期社保新进∩(QFII 增持|北向增仓)→ 信号列表带证据链(组合名/
  变动数/上一期)。
- **双重背书**:社保+QFII 同持且均非战略持股标签。
- **抱团加深**:≥3 组合同持且合计占流通比环比 +0.5pp 以上。
- 反向信号同列(社保集体减持),与掘金台裁决层同一哲学:只标注证据,不做买点。
